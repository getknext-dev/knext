## Non-blocking notes (author's discretion; none change the verdict)

1. **"roughly 7× a pinned cold start" (`:101-102`) rounds up.** The same benchmark's pinned cold start is median **2.28 s** (`…-2026-08-18.md:108`, n=5) and 2317–2748 ms observed (`:51-60`). 14.9 / 2.28 = **6.5×**. "Roughly 7×" is defensible as rounding but "~6.5×" would be exact, and this repo's habit is to prefer the precise number.
2. **Mild tension with the ADR's own later text, worth a cross-reference.** The action-item at `:279` already concedes the tail: "The ~2 s estimate holds at the median and **understates the tail** … max to max +10.7 s." The new paragraph asserts flatly "not the ~2 s the cost model assumed", without acknowledging that the ADR had already recorded a tail caveat. Not a contradiction — a 14.9 s single sample is exactly the tail `:279` warns about, and the two runs used different image sizes (~105 MB / 370 MB / the spike's) — but a future reader may read them as conflicting. One clause ("consistent with the tail caveat recorded below") would close it.
3. **Provenance is one hop deep, and this is the issue's choice, not the PR's.** The cited file *references* the number ("the sampling sitting's 14.9 s first-pull sample") rather than carrying the raw sample. #767 designated that exact file as the source, so the PR is faithful to what was asked; flagged only so nobody later treats the citation as pointing at raw data.
