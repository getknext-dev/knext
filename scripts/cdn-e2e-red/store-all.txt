# Negative control: the same honest apps behind an emulator in `store-all` mode
# (it stores every response whatever its headers say). Every "never cached"
# check must SEE that, or it cannot catch the failure it claims to. This covers
# the checks whose shape Next itself also keeps off the edge on 16.4 (a 405 for
# POST, a redirect without s-maxage, the 307 Next sends an RSC request that has
# no _rsc), where removing knext's condition alone cannot turn them red.
rsc-poisoning|RSC poisoning: a plain request was not served the HTML page
rsc-symmetric|an RSC navigation was served HTML stored under the _rsc key
never-set-cookie|a response carrying Set-Cookie was edge-cached
never-private|a response carrying Cache-Control private was edge-cached
never-no-store|a response carrying Cache-Control no-store was edge-cached
never-authorization|a response to a request with Authorization was edge-cached
never-draft-cookie|a response to a request with the draft-mode cookie was edge-cached
never-non-get|a POST response was edge-cached
never-3xx-vary|a redirect varying on Host/X-Forwarded-Host was edge-cached
never-3xx-static|a prerendered 3xx was edge-cached
cookie-gated-static|a cookieless request got the protected body from the edge
middleware-cookie-variants|variant B was served variant A's body from the edge
dot-segment|a dot-segment path leaked the protected body or was edge-cached
